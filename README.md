# zetrail

[![zotero target version](https://img.shields.io/badge/Zotero-10-green?style=flat-square&logo=zotero&logoColor=CC2936)](https://www.zotero.org)

_**Z**otero **E**vidence **T**raceability &amp; **R**etrieval for **A**uditable **I**ntelligent **L**iterature_, a.k.a. _zetrail_, is a [Zotero](https://www.zotero.org/) plugin.  
A research assistant intended for searching your academic library, verifying claims against source passages, synthesizing evidence across papers, and tracing each result back to the exact document and page.

# 🚀 Quick Start Guide

## Install

- Download the plugin (.xpi file) from below:
  * [Latest Stable](https://github.com/vonexel/zetrail/releases/latest)
  * [All Releases](https://github.com/vonexel/zetrail/releases)
- In Zotero click `Tools` in the top menu bar and then click `Plugins`;
- Go to the Extensions page and then click the gear icon in the top right;
- Select `Install Plugin from file`;
- Browse to where you downloaded the `.xpi` file and select it;
- Finish.
